# Fair Rummy - WebView Android App

Version 1 is intentionally simple: it opens the Fair Rummy GitHub Pages site inside an Android WebView in landscape mode.

URL:
https://onlineexamvzm25.github.io/fairgamesind/

App name: Fair Rummy
Package: com.games.fairrummy
Orientation: Landscape

## Build in Android Studio
1. Open this folder in Android Studio.
2. Let Gradle sync/download the Android Gradle Plugin and dependencies.
3. Connect an Android phone with USB debugging enabled, or create an emulator.
4. Select the `app` configuration.
5. Run the app to test.
6. For an APK: Build > Build APK(s).

This first version does not add extra native screens or features. The purpose is only to verify the GitHub site works correctly inside the Android WebView.
